02 / 精选项目

代表作品

深度剖析两个重点项目：从实际问题、架构设计，到客观评测指标与局限性思考。

NeuralIDOR-Det

深度学习 · API 安全

面向 API 流量的用户与自动化脚本异常行为检测，重点防范越权访问（IDOR）等针对非授权资源的请求。

技术架构

采用 Transformer Encoder 提取 API 调用序列的时序语义，结合多层感知机（MLP）处理网络元数据（IP、user_id、请求频次），通过后期融合（Late Fusion）实现多模态联合决策。

引入自编码器（Autoencoder）在无标注场景下发现未知的潜在攻击模式。

模型可解释性

利用注意力热力图（Attention Maps）可视化关键 API 调用对判定结果的贡献度，使模型决策具备清晰可溯源的审计解释性，拒绝“黑盒推断”。

  • 0.784准确率 (Accuracy)
  • 0.870F1 分数 (F1-Score)
  • 0.666ROC-AUC

客观评估与局限性说明： 目前基线模型 CatBoost 的 ROC-AUC 达到 0.893，当前的混合深度模型在全局 AUC 指标上尚未超越纯树模型。具体归因分析与后续改进方案已在项目 README 中详尽论述。
