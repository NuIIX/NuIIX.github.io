02 / Projects

Selected work

Two key projects, from the problem and approach to honest results and limitations.

NeuralIDOR-Det

Deep Learning · Security

Detecting anomalous behaviour of users and bots in API traffic, primarily IDOR-like requests to resources owned by someone else.

Approach

A Transformer Encoder analyses sequences of API calls while an MLP handles metadata (IP, user_id, request count). Features are combined through late fusion.

An autoencoder looks for unknown attack types without labels.

Explainability

Attention maps show which API calls influenced the model's decision, so the result can be inspected rather than taken on faith.

  • 0.784Accuracy
  • 0.870F1
  • 0.666ROC-AUC

Honest about limitations. The CatBoost baseline reaches ROC-AUC 0.893, so the hybrid model does not beat it on this metric yet. Causes and the improvement plan are described in the project README.

Semantic Gardener

Obsidian plugin · NLP

An Obsidian plugin that finds semantically duplicated notes and carefully merges them into atomic concepts.

Approach

Local embeddings (multilingual MiniLM, ONNX) are computed in a Web Worker. Clustering uses cosine similarity and each duplicate is double-checked with Gemini (BYOK).

UX & privacy

Human in the loop: word-level diff, accept / edit / reject, one-click undo of the last refactoring.

Vault text never leaves the machine during scanning.
