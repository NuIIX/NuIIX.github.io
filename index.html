02 / Проекты

Избранные работы

Две ключевые работы: от задачи и подхода до честных результатов и ограничений.

NeuralIDOR-Det

Deep Learning · Security

Поиск аномального поведения пользователей и ботов в API-трафике, в первую очередь IDOR-подобных обращений к чужим ресурсам.

Подход

Transformer Encoder анализирует последовательности вызовов API, MLP обрабатывает метаданные (IP, user_id, число запросов). Признаки объединяются через late fusion.

Autoencoder ищет неизвестные типы атак без разметки.

Объяснимость

Attention maps показывают, какие вызовы API повлияли на решение модели, поэтому результат можно проверить глазами, а не принимать на веру.

  • 0.784Accuracy
  • 0.870F1
  • 0.666ROC-AUC

Честно об ограничениях. CatBoost-baseline даёт ROC-AUC 0.893, то есть гибридная модель пока не побеждает по этой метрике. Причины и план улучшений разобраны в README проекта.
